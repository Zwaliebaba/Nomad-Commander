## Goal

The host's side of the board: everything the world produced that the company can act on within a stated time, as items with expiry, generated by rules so that a session always contains an arc, including the second source of decisions that is not a fleet. The client (NC-073) only renders what arrives here.

## Deliverables

- `GameLogic/BoardItem.h`: `BoardItemId`, `BoardItemKind { Offer, Threat, Accusation, MarketProjection, Sighting, InsolvencyWarning, OfficerAvailable, IntelligenceOffer, OutpostSeized, ReceiptReady, RebuildStarted }`, `struct BoardItem { kind; createdAtTick; expiresAtTick; payload (the id of the offer, accusation, report, receipt, or an `IntelligenceOffer`); projection text id; }`, `struct IntelligenceOffer { seller (a leader or a broker); subject; price; resolvesAtTick (a short timer); }`.
- `GameLogic/Board.cpp`: `ResolveBoard(World&, Tick, events)` each tick: create items from events (offers from NC-056, accusations from NC-052, sightings from NC-050 filtered to what changes a decision, market projections from NC-045's `Project` when a good will run out within `Tuning::PROJECTION_HORIZON_TICKS`, insolvency from NC-046, officers from NC-065, seizures from NC-066, receipts from NC-064); expire items (opportunities decay: a convoy sighting expires when the convoy's projected passage does; an offer at its expiry); the second source: an `IntelligenceOffer` appears at `Tuning::INTEL_OFFER_CHANCE_PER_DAY` with a purchase that resolves on `INTEL_TIMER_TICKS` into a `PurchasedTip` report (NC-050) with the seller's track record; `Input::BuyIntelligence`.
- The never-empty rule: if the board would hold fewer than `Tuning::BOARD_MIN_ITEMS` actionable items for a company for a day, the daily pass generates one from the second source (GDD §2) and the event says so.
- Log lines: `Decision` for each input already; add `BoardItemShown` with kind for decision-density measurement (NC-101 divides decisions by items).
- `WireBoardItem.h`.
- `GameLogicTests/BoardTests.cpp`: the §3 start produces three items of three kinds with expiries; an offer item lasts at least a day; a sighting expires with the convoy's passage; the never-empty rule fires; an intelligence purchase resolves on its timer into a report with reliability.
